# ChatGPT Chatbot (Node.js + OpenAI API)

An interactive chatbot web app powered by the OpenAI API. Built with Node.js and Express on the backend, and styled with a minimal dark-themed frontend inspired by ChatGPT’s own UI.

This app supports real-time conversations using OpenAI's GPT-3.5-turbo model and showcases how to securely use API keys via environment variables, deploy to the cloud, and maintain smooth UX.

---

## Live Demo: https://node-js-chatbot-b9k5.onrender.com
_(Takes ~30 seconds to load on first visit due to Render's free tier spin-up)_

---

## Features

- **Secure OpenAI API usage** via `.env` & environment variables
- **Styled Frontend** with clean dark UI, message bubbles, and typing indicator
- **Node.js + Express Backend** handles conversation state and API calls
- **Chat History Memory** per session (temporary, not persistent)
- **Live Deployment via Render**
